# Zero-sum sequences

A Python library for computing with finite sequences over additive groups:
zero-sum atoms, factorizations and their lengths, automorphism orbits, and
zero-sum constants.

The core package runs in ordinary Python; Sage is optional. It is intended
for explicit computations on small examples, not a replacement for
structural theorems or a large-scale computation service.
